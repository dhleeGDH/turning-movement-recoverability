# Recoverability characterization for turning-movement estimation

Code and derived data for the paper *A Recoverability Characterization for
Turning-Movement Estimation at Uninstrumented Signalized Intersections*
(Journal of Intelligent Transportation Systems).

The study characterizes what the deployable observables at an uninstrumented
fixed-time signalized intersection permit to be recovered. A turning count is
factored into a demand level and a turn split. A closed-form demand anchor
recovers the level to near a cross-validated achievable-accuracy benchmark,
while no tested estimator class recovers the turn split beyond the frozen
historical split, bounded by a positive-control detection floor of about
0.028 RI. Recoverable accuracy is governed by the residual same-clock-hour
demand variability.

## Data availability

The synthetic networks and their scenarios are generated by the code
(`synthetic_demand.py`) and require a SUMO installation. The Bucheon
turning-movement counts are available from AI-Hub, a Korean-government open-data
platform that requires registration and provides an English-language application
process for international researchers. The Xuancheng data are available from
Figshare (doi:10.6084/m9.figshare.29925824) under their original licence; the
turning movements used here are reconstructed from the released vehicle
trajectories, and the reconstruction code is not redistributed. The `data/`
directory holds the derived movement-by-window tables sufficient to reproduce the
reported RI computations without direct platform access, limited to aggregates
whose redistribution the source licences permit.

## Reproduction

Generate the synthetic scenarios, then run each stage. The demand anchor, the
achievable-accuracy benchmark, and the split-probe battery run on CPU.

    pip install -r requirements.txt
    python -m src.od_gen                        # generate SUMO grids and scenarios
    python -m src.pilot_cluster                 # anchor recovery and RI by hop depth
    python -m src.achievable_benchmark          # achievable-accuracy benchmark
    python -m src.split_positive_control        # split detection floor
    python -m src.known_ceiling_calibration     # ceiling calibration
    python -m src.ipf_baseline                  # classical baseline
    python -m src.bucheon_apply                 # Bucheon site evaluation

The DART probe (`dart_pretrain.py`) additionally requires PyTorch and the pinned
GraphPFN and LimiX backbones. The demand-anchor results that carry the
characterization reproduce without it.
